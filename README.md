# e-plantShopping

## Project Overview

**e-plantShopping** is a React-based e-commerce application that allows users to browse and manage a collection of plants available for purchase.

The application focuses on state management using React's **useReducer** hook as the primary state management solution. This approach helps centralize application logic, improve maintainability, and manage complex state updates efficiently.

## Features

* Display a catalog of plants
* Add plants to the shopping cart
* Remove plants from the shopping cart
* Update cart quantities
* Calculate total items and total price
* Centralized state management with `useReducer.`
* Responsive user interface

## Technologies Used

* React.js
* JavaScript (ES6+)
* HTML5
* CSS3
* React Hooks (`useReducer`)

## State Management

The project uses the **useReducer** hook as the main state management mechanism. The reducer handles actions such as:

* Adding products to the cart
* Removing products from the cart
* Updating product quantities
* Managing cart totals

This structure provides predictable state transitions and makes the application easier to scale.

## Installation

Clone the repository:

```bash
git clone https://github.com/your-username/e-plantShopping.git
```

Navigate to the project directory:

```bash
cd e-plantShopping
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm start
```
